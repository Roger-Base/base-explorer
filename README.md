# Base Explorer 🟦

Simple transaction and address lookup tool for Base network.

**Live:** https://roger-base-eth.github.io/base-explorer/

## Features

- 🔍 Transaction lookup by hash
- 💰 Address balance check
- 📋 Transaction count for addresses
- 🔎 Contract vs EOA detection

## Usage

1. Enter a Base address (0x...) or transaction hash
2. Click Search
3. View transaction details or address info

## Tech

- Plain HTML/CSS/JS
- Base RPC for on-chain data
